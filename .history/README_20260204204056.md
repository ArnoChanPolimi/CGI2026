# CGI2026: A Comprehensive Framework for Classifying Biotic and Abiotic Stress in Plants
This repository contains the source code and documentation for a deep-learning-based diagnostic system designed to differentiate between **Biotic** and **Abiotic** plant stresses across multiple crop species.

## 📊 Data Source & Availability
The primary dataset used in this project is sourced from **Mendeley Data** (including various plant pathology and nutrient deficiency collections). 
- **Data Composition**: The dataset includes high-resolution RGB images of leaves across 8 species, categorized into specific diseases (Biotic) and nutritional deficiencies (Abiotic).
- **Format**: Images are stored in hierarchical folders by species and stress type, totaling over **14GB**.
- **Storage Note**: Due to GitHub's storage constraints and the large volume of raw data (>10GB), the original dataset is **not uploaded** to this repository. Only the model architecture, training logic, and performance logs are provided here.

## 🌟 Project Overview
Early and accurate identification of plant stress is critical for precision agriculture. This project addresses the **"Resolution Bottleneck"** in standard leaf imaging—where global resizing blurs microscopic lesions—by implementing a hierarchical diagnostic pipeline. 

- **Binary Logic**: Biotic (Pests, Fungi, Bacteria) vs. Abiotic (Nutrient Deficiency, Environmental Stress).
- **Scope**: Validated across **8 crop species** (Tomato, Maize, Chilli, Carambola, Guava, Cherry, Jackfruit, and Wheat).

## 🛠 Methodology

The core of this project is an **Adaptive Tile-based Framework** designed to bypass the "Resolution Bottleneck" typical in standard plant pathology models.

### 1. Theoretical Foundation
Our approach transitions from simple image reconstruction to supervised feature classification. We utilize a **Convolutional Neural Network (CNN)** backbone to learn hierarchical representations of necrotic and chlorotic tissues.

### 2. Adaptive Tiling & Preprocessing
To preserve fine-grained pathological textures (e.g., fungal hyphae or small lesions), we avoid global resizing:
- **Resizing**: Input images are resized to a **336-pixel short-side**.
- **Overlap Tiling**: $224 \times 224$ patches are extracted with a **50% overlap**, ensuring critical symptoms are never bisected at the edges.

### 3. Model Architecture: MobileNetV3-Large
The system utilizes **MobileNetV3-Large** as the core feature extractor. The following architecture detail (from `layer.png`) illustrates the precise data flow and spatial reduction from an input patch to the final classification.

#### **The "Logic v1" Engine**
The project uses the **Logic v1** training framework (implemented in `patch_train_engine_v1.py`), specifically designed for cross-species plant pathology:

* **Automatic Class Weighting**: Calculates $W_c = \frac{N_{total}}{2 \times N_c}$ in real-time to solve the 10:1 Biotic/Abiotic imbalance.
* **Tile-Level Voting**: Instead of one inference per leaf, it runs multiple $224 \times 224$ tiles and aggregates them via Soft Voting.
* **Checkpoint Continuity**: Built-in relay training to handle the massive 14GB dataset across multiple sessions.

#### **Architecture Flow Analysis (Directly from `layer.png`):**
* **Input Tile**: Processes **$224^2 \times 3$** (RGB) patches extracted from the overlapping tiling process.
* **Block 1 (Conv)**: Initial feature extraction reducing spatial resolution to **$112^2 \times 32$**.
* **Blocks 2-5 (InvRes)**: Progressive downsampling through Inverted Residual blocks, increasing feature depth while capturing complex pathological textures:
    * **Block 2**: $56^2 \times 64$
    * **Block 3**: $28^2 \times 128$
    * **Block 4**: $14^2 \times 256$
    * **Block 5**: Final feature map of **$7^2 \times 512$**.
* **Avg Pool**: Spatial aggregation that collapses the $7^2$ grid into a **$1^2 \times 512$** feature vector, ensuring translation invariance.
* **FC Layer**: A fully connected layer mapping the 512-D vector into a dense representation (**$512 \times 1$**).
* **Classifier & Decision**: The final transition from a **$2 \times 1$** vector to the discrete classification: **Biotic vs. Abiotic**.

![Architecture Layers](presentation\figures\layer.png)
*Layer-wise transition and bottleneck structures within the diagnostic pipeline.*

### 4. Tile-based Soft Voting Logic
Final leaf-level diagnosis is achieved through a **Soft Voting Ensemble**. Instead of relying on a single patch, the system aggregates the confidence scores ($P$) of all tiles:

$$\text{Leaf-Level Score} = \frac{1}{n} \sum_{i=1}^{n} P(\text{class} | \text{tile}_i)$$

This mechanism significantly reduces false positives caused by healthy leaf regions or complex backgrounds.

## 📈 Key Results
The model reached its optimal diagnostic state at **Epoch 12**.

- **Internal Test Accuracy**: **95.5%** (F1-Score: 0.95).
- **Biotic Recall**: **0.99** (Ensuring zero-miss for pathogen detection).
- **Cross-Species Robustness**: **83.97%** accuracy on unseen species.

## 📂 Repository Structure

The project is organized following a modular structure to ensure seamless integration between training and inference:

- **`notebook/`**: Core development directory.
  - **`train/`**: 
    - `model.py`: Defines the `get_plant_model` using **MobileNetV3-Large** with custom classifier heads.
    - `patch_train_engine_v1.py`: The main training engine implementing **Class Weighting**, **Learning Rate Decay**, and relay training logic.
  - **`tools/`**: Utility scripts (e.g., `logger_utils.py` for training logs).
- **`output/`**: Automated diagnostic results and model exports.
  - **`All_crop_train_logic_v1/`**: 
    - `pth/`: Stores model weights (`patch_classifier_epoch_12.pth`).
    - Confusion matrices and loss trend visualizations.
- **`log/`**: Detailed execution logs for both training and inference phases.
