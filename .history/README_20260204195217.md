# CGI2026: Cross-Species Plant Stress Diagnostic System

This repository contains the source code and documentation for a deep-learning-based diagnostic system designed to differentiate between **Biotic** and **Abiotic** plant stresses across multiple crop species.

## 🌟 Project Overview
Early and accurate identification of plant stress is critical for precision agriculture. This project addresses the "Resolution Bottleneck" in standard leaf imaging by implementing a hierarchical diagnostic pipeline. 

- **Binary Logic**: Biotic (Diseases/Pests) vs. Abiotic (Nutritional/Environmental).
- **Scope**: Validated across **8 crop species** (Tomato, Maize, Chilli, etc.).

## 🛠 Methodology
Instead of resizing global leaf images, which blurs microscopic lesions, we employ an **Adaptive Tile-based Framework**:

1. **Preprocessing**: 336-pixel short-side resizing + 50% overlapping tiling ($224 \times 224$).
2. **Architecture**: **MobileNetV2** (Pre-trained on ImageNet) for efficient feature extraction.
3. **Decision Logic**: **Soft Voting Ensemble**—aggregating confidence scores from multiple tiles for a robust leaf-level diagnosis.
4. **Imbalance Handling**: **Automatic Class Weight Compensation** to handle the scarcity of Abiotic samples.



## 📊 Key Results
The model reached its optimal performance at **Epoch 12**.

- **Internal Test Accuracy**: **95.5%** (F1-Score: 0.95).
- **Biotic Recall**: **0.99** (Ensuring high sensitivity for pathogen outbreaks).
- **Cross-Species Robustness**: **83.97%** accuracy on unseen species.
